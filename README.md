# ZH Development · Marketing

Material de marketing de ZH Development: videos para Instagram, brand kit y guiones.

- `docs/brief.md`: contexto, referencia de estilo, tokens de marca y pendientes.
- `docs/llamada-perfecta.md`: playbook de prospección con datos: qué hacer, qué decir, WhatsApp, horarios.
- `docs/guiones-llamadas.md`: guion literal de las 8 llamadas de calentamiento.
- `docs/llamadas-calentamiento.md`: investigación de cada empresa, dolor probable y pitch.
- `docs/dialogo-ejemplo-ventas.md`: una llamada completa de ejemplo.
- `brand/`: logo y assets de marca.

Los renders de video (`out/`, `renders/`) no se versionan.
