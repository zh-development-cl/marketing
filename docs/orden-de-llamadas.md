# Orden de llamadas: las 40 por probabilidad de cierre e importancia

Fecha: 2026-10-14. Se llama primero a las de menor probabilidad y menor importancia, para practicar donde un error cuesta poco, y se guardan las mejores para cuando el pitch esté rodado.

## Cómo se puntuó

**Probabilidad de cierre, 1 a 5.** Qué tan claro es el dolor desde el sitio, si ya usan un sistema que se pueda conectar, si el contacto decide, si ya mostraron interés, y si la empresa parece viva. Baja cuando ya tienen tecnología propia, cuando la decisión está en otra parte, o cuando no pudimos ver nada.

**Importancia, 1 a 5.** Tamaño del proyecto probable, si sirve como caso de éxito para el rubro, si puede traer más clientes, y si abre un segmento que ZH quiera repetir.

**Orden:** suma de las dos, de menor a mayor. Es un juicio hecho desde los sitios web, no un dato. Después de cada llamada, corrijan la nota con lo que escucharon.

## Cómo usar la lista

- **Las 13 primeras** son la práctica real: si se quema una, no pasa nada. Ahí se ajusta el guion.
- **De la 14 a la 32** es el bloque grande. Cuando lleven cinco conversaciones reales, ya saben qué objeciones vienen.
- **Las 8 últimas** se llaman con el pitch probado, en el mejor horario, y con LinkedIn mandado dos días antes.
- **Tribú** es la excepción: ya mostró interés una vez. Si prefieren, llámenla apenas tengan tres conversaciones hechas, antes de que se enfríe más.
- Las notas son hipótesis. Después de cada llamada, cambien la probabilidad según lo que escucharon y reordenen.
