## Checklist para dejar la cuenta lista

1. Crear la cuenta con `contacto@zhdevelopment.cl` (si `@zhdevelopment` no es de ZH, usar `@zhdevelopment.cl`).
2. Subir la foto de perfil y pegar nombre, bio, enlace.
3. Configuración → Tipo de cuenta → Cambiar a cuenta profesional → Empresa → categoría.
4. Vincular una página de Facebook de ZH Development (crearla si no existe). Sin esto no se puede publicar por la API de Meta.
5. Activar autenticación en dos pasos.
6. Dejar la cuenta pública.
